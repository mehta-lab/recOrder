# recOrder

The `recOrder` repository is now an archive. 

All of `recOrder`'s functionality and future development has been migrated to the [`waveorder` repository](https://github.com/mehta-lab/waveorder), where GUI, CLI, and API are co-developed in the same repository.

**Migrating `recOrder` users** can make a new environment, `pip install waveorder`, and use `waveorder` GUI and CLI calls as a drop-in replacement for `recOrder` calls.

`recOrder`'s PyPI package will stay online, so `pip install recOrder-napari` will continue to support earlier releases.
